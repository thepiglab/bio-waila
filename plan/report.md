# Pass-2 classifier dataset plan

Generated by `bio_waila/data/select.py` from 1,898 eligible registry datasets (budget 600,000 images, 2,000 per dataset, 6,000 for rare classes).

- **420 datasets**, about **872,309 images** planned (366 train / 54 validation datasets, split by dataset group).
- Licence groups: **nc** 9 datasets / 43,114 images, **permissive** 411 datasets / 829,195 images. `nc` = non-commercial (tier B), an optional layer: training excludes it unless `include_nc` is on.
- MMBU source datasets (plan/mmbu_sources.json) in the plan: 47, covering 1,395 of 3,147 public rows.
- Download routes: zenodo 156, hf 107, figshare 74, kaggle 33, direct 17, mendeley 16, doi 9, openneuro 4, dataverse 4.
- MMBU overlap: 171 low, 134 medium, 113 high, 2 unknown (non-low listed in disclosure.csv). High-overlap datasets are allowed because this classifier only labels data for training and is never submitted; mmbu-public stays eval-only and near-duplicates of it are removed in prepare.py.

## Label quality per head

Labels are dataset-level. *hard* = one value for every image; *candidates* = one of several, train with a partial-label loss; *multi* = all values apply; *masked* = no usable label (excluded from that head's loss).

## Classes with no training dataset

These appear in MMBU's vocabulary but no selected dataset carries them. Add data by hand or expect the model to fall back on related classes.

- **submodality**: differential fluorescent microscopy, specular microscopy
- **body_part**: abdominal organs, appendicular skeleton, arteries, blood cells, blood vessels, cell, eosinophils, genitourinary system, lymphatic system / bone marrow, lymphocytes, male genitourinary system, monocytes, musculoskeletal system, neutrophils, reproductive system, retroperitoneum, white blood cells
- **stain**: alexafluor-tubulin, fluorescent beads, lysotracker, tetraspeck beads
- **specimen**: breast tissue, colon cancer cells, guinea pig, leishmania haptomonad, liver tissue, mouse embryo cells, p. falciparum-infected red blood cells, red blood cells, tissue, tobacco
