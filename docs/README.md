# Docs index

One line per document. Start with [OVERVIEW.md](OVERVIEW.md); the data pipeline walkthrough is the one to read before changing code. References to `data_discovery/` and `mmbu-public/` point at sibling directories of this repo in the `mmbu/` workspace.

- [experiments/training_plan.md](experiments/training_plan.md): **the final training plan** (2026-10-07): which teachers and student to train, how the data feeds them, run order on 4× B200, questions for the organizers. Start here for training.
- [OVERVIEW.md](OVERVIEW.md): the decision (Jev-style model on Gemma 4 plus a CLM-style classifier on SigLIP2), label design conclusions, and the experiment plan in one place.
- [QA.md](QA.md): the latest repo QA pass: tests added, slurm changes, bugs found in `src/`.

## data/

- [../catalog/DATA.md](../catalog/DATA.md): **the list of training datasets**: name, link, size, modality, short description (machine-readable: `catalog/datasets.yaml`; rebuild with `scripts/build_catalog.py`).

- [data/pipeline.md](data/pipeline.md): maintainer's walkthrough of select, download, metalabel, prepare and validate; where fixes go; how to add a dataset.
- [data/label_design.md](data/label_design.md): how MMBU's six fields are labelled in practice, derived from the public split, and the dataset-level training rules (generated by `scripts/label_design_analysis.py`).
- [data/label_rules.json](data/label_rules.json): the machine-readable form of those rules.
- [data/pass2_vocabulary.md](data/pass2_vocabulary.md): MMBU's closed vocabulary per field with counts (copy in `resources/pass2_vocabulary.json`).
- [data/audits/](data/audits/): per-dataset metadata audits A to E (access, labels, matcher fixes); each `audit_*.md` has a `.jsonl` with the machine-readable verdicts that `waila-select` reads.
- [data/discovery/](data/discovery/): searches for datasets of rare submodalities (`discovery_rare_A.md`, `discovery_rare_B.md`).
- [data/validation/](data/validation/): image-level validation reports: V1–V7 (first pass), R1–R4 (re-validation after fixes), N1–N4 (newly selected datasets). Each `.md` has the fix blocks merged by `scripts/merge_validation_fixes.py`.

## experiments/

- [experiments/training_plan.md](experiments/training_plan.md): final plan; supersedes the model choices below.
- [experiments/experiment_plan.md](experiments/experiment_plan.md): the full experiment matrix, metrics, decision rules and statistics (about 660 H100-hours).
- [experiments/zoo.md](experiments/zoo.md): the model zoo: zero-shot benchmark of released models on mmbu-public Pass 2 (generative and decision modes, mapping, how to add a model).
- [experiments/b200_plan.md](experiments/b200_plan.md): the same plan scheduled onto up to four B200s, with the data critical path and day-0 checklist.

## models/

- [models/backbones.md](models/backbones.md): which backbone to use for the CLM-style or Jev-style classifier: candidates with licenses, active parameters including the vision tower, and track fit.
- [models/jev_methods.md](models/jev_methods.md): how to adapt Jev-style decision models to closed-vocabulary, multi-field image labelling.
- [models/jev_recipes_index.md](models/jev_recipes_index.md): index of public decision-model recipes (Strands, Clef, Intern and others) and what to copy from each.
- [models/clm_methods.md](models/clm_methods.md): CLM-style cosine classifiers on frozen encoders, and how they handle tail classes.
- [models/medgpt_oss.md](models/medgpt_oss.md): notes on UFNLP/MedGPT-oss as a possible base or comparison.
- [models/med_encoders.md](models/med_encoders.md): medical vision encoders (MedSigLIP, BiomedCLIP, MedImageInsight, BMC-CLIP, pathology/ophthalmology specialists), with origin and license checks (2026-10-07).
- [models/general_encoders.md](models/general_encoders.md): general vision encoders as of 2026-10-07 (SigLIP 2, DINOv3, PE, C-RADIOv4, TIPSv2, EmbeddingGemma 2) and the CLM fine-tuning recipe with sources.
- [models/decision_index_2026-10.md](models/decision_index_2026-10.md): fresh read of the HF Decision Index and JevBench (2026-10-07): eligible small models, recipes of top entries, implications for the Jev teacher.
- [models/clm_llm_vs_encoder.md](models/clm_llm_vs_encoder.md): should a CLM start from a frozen multimodal LLM (as the original CLM does) or a contrastive vision encoder? Evidence, readout choices, costs (2026-10-08).
- [models/moondream31_for_clm_jev.md](models/moondream31_for_clm_jev.md): Moondream 3.1 as a backbone for each teacher: checkpoint layout, vision tower → SigLIP mapping, kestrel API limits, licence (2026-10-08).
- [models/liquid_ai.md](models/liquid_ai.md): Liquid AI's d1 decision models and LFM2.5-VL, as a voter and as a Track-3 student alternative.
