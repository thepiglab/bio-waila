## Pipeline bugs

1. dataverse zip-range open is not retried on 403 (download.py, `sample_zip_remote`: the retry/backoff loop only wraps `z.extract`, not `RemoteZip(url, session=S)`; `infolist()` also unprotected). dataverse.no's Azure gateway returns 403 to roughly 15-25% of range requests at random. Repro: `for i in 1 2 3 4 5 6; do curl -s -L -r 0-99 -o /dev/null -w "%{http_code} " https://dataverse.no/api/access/datafile/233915; sleep 2; done` gives mostly 206 with an occasional 403; `uv run waila-validate --only crc-ihc-cish-he-epithelium --redo --retry` fails with `RemoteIOError: 403 ... datafile/<id>` (a different id each run). Wrap the RemoteZip construction in the same 6-attempt backoff, and skip an archive that keeps failing instead of aborting the dataset.
2. Archive choice order for multi-zip records: `archive_rank` ends with `-size`, so the largest zip (miR-145.zip, 89 GB) is tried first, which maximises exposure to bug 1 and ignores that HE.zip is the only H&E archive (the dataset-level stain label then stays candidates). Workaround used: exclude_paths with a negative lookahead on archive names.
3. Wasted downloads for unreadable formats: axonem downloaded a 1.94 GB zip whole and biosr 1.6 GB before discovering all members are .h5 / .mrc (status `error`, note only `streaming failed: ModuleNotFoundError`). Listing the zip central directory first (as zip-range does) and failing early with an "unsupported format: h5/mrc" note would save the bandwidth and give a clearer report. Repro: `uv run waila-validate --only axonem --redo`.
4. WSI datasets without openslide: mitos-wsi-ccmct downloads 1.47 GB of .svs then every file fails `import openslide` (`reader_error:ModuleNotFoundError`: 2), status "no images prepared". Check `import openslide` before downloading wsi-kind members, or report `blocked: needs --extra wsi`. Repro: `uv run waila-validate --only mitos-wsi-ccmct --redo`.
5. prepare has no aspect-ratio filter: bacteria-species-microtraps-4 keeps 17-19 px x 512 px strips (informative() only tests contrast). Suggest dropping images whose short side after resize is < ~64 px or aspect > 8:1. Repro: `uv run waila-validate --only bacteria-species-microtraps-4 --redo`, all samples are 19x512.
6. Numeric measurement columns reach the review list: neonatal-anthropometric-images csv columns such as `Total Body Length` ('48cm', '45cm') are proposed as body_part review values (field=body_part, class empty). Harmless here because the registry label is hard, but it adds noise to review.csv; columns whose values are all number+unit could be skipped in profiling.
