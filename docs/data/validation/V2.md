## Matcher / pipeline bugs found (each with a minimal reproduction)

Matcher (rules.py / metalabel.py)

1. **View position PA is mapped to chest x-ray for any body part.** `match_value("PA", "dicom:ViewPosition", cls)` returns `{'submodality': ('chest x-ray', True)}`. On check-cohort-hip-knee (knee PA/lateral radiographs) this produced 32 conflicts with the registry-hard digital radiography; with a masked registry the knees would be labelled chest x-ray. Fix: map PA/AP/LAT in CODES only when the body part resolved to chest (or drop PA/AP from CODES['submodality'], keep PATH_CODES chest context).
2. **Column-name regex for body_part matches substrings.** `field_of_column("csv:x.xlsx:Aspartate transaminase (U/L)")` returns `body_part` ('As-**part**-ate'); also `Hospital site` and `Partition`. phlf-gd-eob-liver-mri-2026 puts numeric lab values into review.csv as body_part. Fix: require word boundaries in FIELD_COLUMNS.
3. **Diagnosis label columns are mapped to organs.** `match_value("chronic_heart_failure", "hf:label_name", cls)` returns `{'body_part': ('heart', True)}` ('failure' is not in the `_DIAG` regex) and `match_value("{'not_chronic_heart_failure': 0, 'chronic_heart_failure': 1}", "hf:classes_to_idx", cls)` does the same on a stringified dict (nirschl-heart-failure-2018). Add `failure|insufficiency|class`-style words to `_DIAG`/SKIP_COLUMN, and skip `classes_to_idx`/dict-looking values.
4. **Plain `fluorescence` is only a weak modality hit, so a folder pair fluorescence/brightfield is never trusted.** `match_value("fluorescence", "path:d3", cls)` returns `('fluorescence microscopy', False)` while `"brightfield"` is strong, so the column covers only 50% < COLUMN_MIN and deepbacs-saureus-widefield-seg stays 100% candidates. Fix: make an exact folder token `fluorescence`/`fluorescent` strong in a path column (as `brightfield` is), or let weak hits count toward share when the other values are strong hits of the same field.
5. **Dataset-folder keywords label every file.** `match_value("ground_truth_and_synthetic", "path:d1", cls)` returns `specimen: synthetic (strong)`, so a mixed real+synthetic zip is trusted as synthetic (spcyclegan-synthetic-nuclei-3d-purdue); `match_value("Fundus-AVSeg", "path:d1", cls)` returns modality/submodality from the dataset name (correct there by luck). Constant single-valued top-level folders (nd=1 at path:d1) should not be treated as evidence.
6. **Path strings in a column named Folder are matched as organ.** `match_value(r"C:\Users\...\kidney-QualiAnnotation\images", "csv:a.csv:Folder", cls)` returns `body_part: kidney (strong)` and the column is trusted (zebrafish-pronephros-cystic). Add `folder|dir|directory` to SKIP_COLUMN or skip values containing path separators.
7. **Headerless list files are read as tables whose first data row becomes the header.** microvision-fluorescence-cell-detection: 92 `test_rn_n.csv`/`ImageSets/Main/*.txt` files gave ~570 junk columns, some trusted (`csv:...:cell - neuroblastoma phalloidin` with values like `cell - erythroblast dapi` mapped to dapi). bsubtilis-spore-germination-tracking: ~60 `man_track.txt` tracking files gave >150 junk columns. Fix: sniff for a header (first row non-numeric and not duplicated in data) and require the key column to match media names on >=50% of rows.
8. **File-name tokens are never metadata.** `path_columns("files/Laser_11 D7 IR.tif")` returns `{}`; `path_columns(".../Human_Heart_Asp_ST_Sample.png")` has no organism/organ column; `.../field0642.jpg` vs `.../positive_video_034_00000041.jpg` carry the stain. Affects mouse-rvo-ffa-slo-oct-sichuan-2024 (Mcolor/IR/FFA/OCT suffix decides submodality), tryp-v2-v3-2026 (field* = Giemsa, positive_video* = unstained), stimage-1k4m (Human_/Mouse_ + organ), freehand-us-forearm-v1 (RH/LH). `bids:suffix` only fires when the stem contains '-'. Expose `path:name` tokens (split on space/underscore/dot) as columns so overrides can map them.
9. **cross_field cannot narrow modality when the submodality is shared by two modalities.** intraoral-caries-ahmed-2025: submodality hard 'clinical photography', modality stays {clinical photography, optical imaging}; the modality candidate set should prefer the parent whose name equals the submodality.
10. **Overrides vs registry hard labels.** (Design note, not a crash.) pix2pix-huvec-turku-virtual-staining and deepbacs need per-folder modality, which is impossible while the registry is hard; the registry must be set to masked/candidates first (see the labels block).

Download / prepare (download.py, prepare.py, validate.py)

11. **HF ClassLabel names are dropped.** `hf_rows.jsonl` stores the integer (`hf:label = 0/1`), not the class name. raabin-wbc (names `["Mask","Original"]`, 79 of 140 sampled rows are masks, 3 of 8 inspected images were binary masks), oct2017-kermany, bone-marrow-cytomorphology, derm12345, nes-plankton all lose their label names. Repro: `curl https://datasets-server.huggingface.co/info?dataset=S-AIR-L/RaabinWBC_microscopic_blood_cell_dataset` shows names Mask/Original while hf:label shows 0/1. Fix: write `features[col].int2str(v)` for ClassLabel and drop rows whose label/column name matches mask|segmentation|annotation.
12. **HF streaming errors during iteration are not caught.** kvasir-capsule: `ValueError: Invalid string class label` is raised inside `for ex in it` (outside the try that falls back to hf-files), so the whole dataset errored. (Fixed by the coordinator; bracs also logs `streaming failed: ValueError`.)
13. **HEAD on a pre-signed redirect URL returns 403.** captiv8: `https://dataverse.no/api/access/datafile/196626` 303-redirects to an S3 URL; `curl -s -H "Range: bytes=0-1023" <signed>` gives 206 but HEAD gives 403 SignatureDoesNotMatch; the harness reports `RemoteIOError 403` and still fails after the coordinator's fixes. pediurf (figshare S3, X-Amz-Expires=10) failed the same way before the fix.
14. **Unsupported archive types.** `.rar`: reta-benchmark (6.6 MB images.rar fetched but never extracted; prepare tries to read the rar as TIFF), colorectal-polyps-gaze (365 MB), angiocad (4 x 4 GB), rarpl6-workflow (38 GB); `.7z`: deepcytometer-klf14-mouse-wat; split zip `.zip.001-.005`: plasmodium-4species-rtdetr-france-2023; zip with an unsupported compression method: curvas-2024 (`NotImplementedError: That compression method is not supported`). `bsdtar` is installed and extracts RAR; for small rars a plain extract step is enough.
15. **MetaImage headers sampled without data files.** shoulder-3d-us-mosaicking: zip-range fetched 35 `.mhd` files (8,969 bytes total) but not the `.raw/.zraw` named in ElementDataFile, so all 35 failed with RuntimeError. Fetch the sidecar when sampling `.mhd`/`.hdr`.
16. **NIfTI slicing ignores orientation.** hvm-hepatic-vessel-map (sagittal/coronal slices mixed with axial, rotated 90 degrees), trusted-3dus-ct-kidney (CT slices are sagittal; US en-face planes), phlf-gd-eob-liver-mri-2026 (slices flipped). Pick the through-plane axis from the affine (reorient to RAS) before slicing.
17. **Multi-channel `.npy` decode picks one channel.** fucci-rpe1-cellcycle-naef-2025: images decoded as transmitted-light crops although the dataset is FUCCI fluorescence.
18. **Whole-archive/stream sampling takes the first members.** bicervi-2026 (only the NILM class archive of 9 files), cross-choleact (only one patient video CholeCANE_09 from the tar), tryp-2023 (sample dominated by video frames). Sample across archives/classes.
19. **Mask/derived-image filter misses.** bsubtilis `22_OP/res_seg043.tif` (result segmentations), pix2pix `Quality Control/.../RSE_GTvsSource_*.tif` and `*_real_A.png` (model outputs and error maps), bracs `assets/distribution/*.png` (bar charts), cbis-ddsm DICOM `SeriesDescription: cropped images` (lesion crops; no DICOM-series exclusion available), han-severance montage sheets. exclude_paths cover the first three; a DICOM series filter is missing.
20. **--max-gb is exceeded by `whole` zips (before the coordinator's fix):** hep2-cell-cycle-2026 2.77 GB, zebrafish-embryo-phenotypes 2.09 GB, bsubtilis 2.5 GB, drac-2022 2.2 GB, stimage-1k4m 4.15 GB on disk, intraoral 3.3 GB, fdr26 3.4 GB. Also the host disk reached 98% (phlf failed with ENOSPC) - the cache cap does not guard the free disk; `uv run waila-cache status` now prints a disk-free line.
21. **Decoding of low-range/16-bit and pseudo-colour data.** arabidopsis-root-zone-segmentation-hpts renders as a saturated red field (single channel mapped to red); pan-multiplex-nimbus channels decode near-black. Normalise per image and map single channels to grey.
22. **Duplicate-heavy sources collapse under dedup**: hushem (VQA rows repeat each image), evisan (4107 of 6000 frames), arabidopsis (132 dupes), arcade (repeated image_id) - expected, but the plan's per-dataset image targets (2000) are unreachable for these; do not count them toward submodality quotas.
