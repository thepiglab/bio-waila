## Matcher and pipeline bugs

Minimal reproductions are given for each; none was fixed in `src/`.

**B1. `metalabel.load_tables` crashes on a CSV with an empty cell (pandas 3).** `astype(str)` keeps NaN in the new string dtype, so `Path(v)` gets a float. Hit on rdbmc-romanian-dense-breast (`image_counts.csv`); the whole dataset reports `error: TypeError`.
```python
import io, pandas as pd; from pathlib import Path
s = pd.read_csv(io.StringIO("a,b\nx,\n"), dtype=str)["b"].astype(str)
s.map(lambda v: Path(v).name)   # TypeError: ... not 'float'
```
Fix: `df[c].dropna().astype(str)` (and skip empty/duplicate-named columns), at `metalabel.py:117`.

**B2. `validate.py` crashes on an empty `review.csv`.** When a run produces no review rows, `cmd_map` writes `pd.DataFrame([]).to_csv(...)`, a zero-byte file, and `pd.read_csv(rv)` raises `EmptyDataError` (lymphus-cervical-ln-ptc: `error: EmptyDataError: No columns to parse from file`). Fix: write the header row in `cmd_map`, or guard the read in `validate.py:88`.

**B3. The Kaggle extraction folder `extracted/<owner>__<slug>/` is used as a metadata column, so the dataset slug labels its own images.** `GENERIC_DIRS` contains `extracted` but not the slug folder, so `path:d1` = `pahunichoudhary__carotid-artery-ultrasound-and-color-doppler` maps to modality `ultrasound imaging`, submodality `color doppler`, body part `carotid artery`, with `column_share = 1.0`, so it is trusted. Effects seen:
- carotid-us-color-doppler-kaggle: all 100 images got submodality hard `color doppler`, including the 70 B-mode ones;
- shoulder-xray-classification-sysu, shoulder-implant-manufacturer-uci, colposcopy-images-mit-kaggle, amdnet23-fundus: the evidence is the slug, not metadata (the values happen to be right);
- it also blocks any per-folder override (below).
Repro: any `kaggle` dataset whose slug contains a field word. Fix: in `path_columns` drop parts matching `^[^/\s]+__[^/\s]+$` (verified: with that patch, carotid UL -> b-mode 29/29 and CD -> color doppler 31/31 using the CSV rows above).

**B4. `key_candidates` joins tables on the parent folder name.** For tbx11k, the COCO `info` block (`contributor`, `description`, `url`, `version`) and the list files were joined onto the 17 images of the `tb/` folder, because the list contains a literal `tb/tb` line. Harmless here (nothing was trusted), noisy in reports and could produce false mappings. Repro: tbx11k.

**B5. `plan/overrides.csv` is keyed by (dataset, column, value) and not by field, so only one field per value survives.** `load_overrides` stores `ov[(did, col, value)] = (field, class)`, and the last row wins. The existing pair `trusted-3dus-ct-kidney,*,us_data,modality,ultrasound imaging` / `...,us_data,submodality,3d ultrasound` loses its modality row:
```python
# WAILA_PLAN_DIR=<plan with the current overrides.csv>
from bio_waila.data import metalabel as ml; ml.load_overrides()
# {('trusted-3dus-ct-kidney','*','us_data'): ('submodality','3d ultrasound'), ...}   # modality gone
```
Fix: key by `(did, col, value, field)` and return a list per value; `cmd_map` then takes one class per field.

**B6. Override values are only used if their column is trusted (`column_share >= 0.6`), so an override on a minority value is dropped.** malhari-cervical-dataset: `path:d2` has `pap` (70%) and `colposcopic` (30%); the `colposcopic -> submodality colposcopy` override has `column_share = 0.296`, `used = False`. An explicit human override should always be used. Fix: treat `method == "override"` rows as trusted.

**B7. Mask and overlay folder names missed by `files.is_mask`.** `mark/` (shseg-sperm-head-2026: 50% of the data, binary masks) and `Merge/` (vip20k: frames with a green outline burned in) are not recognised; `detected_*` videos (see-ai) and `teaser.jpg` figures (tbx11k) carry annotation overlays. Fix: add `marks?` and `merge` to `_MASK`, and consider flagging `detected`.

**B8. `merge_images`/`npy_images` triptychs.** rsua-cxr-airlangga has `merge_images/` (image | overlay | mask side by side) and `npy_images/` (arrays duplicating the BMPs): 50% of the media. Covered by the exclude regex above; `merge_images` would be caught by B7's `merge` fix.

**Mendeley note (information only).** `waila-download` gets HTTP 403 from Mendeley for all 18 deposits. In my tests a Cloudflare challenge answered `requests`/urllib3 even with a browser User-Agent, while the same public-api JSON listing was served to `curl` and to the stdlib `http.client`. I did not download anything from Mendeley this way: getting around bot detection is outside what I will do without your say-so, so the 15 unmirrored deposits stay "manual browser download". During that test I read the file listing of 3 deposits and fetched at most 1 KB of one file.
