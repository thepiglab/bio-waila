## Pipeline bugs

1. **HF dataset-script repos fail with `RuntimeError`** (`gomez-human-embryo-timelapse`). `datasets.load_dataset('1aurent/Human-Embryo-Timelapse', streaming=True)` raises `Dataset scripts are no longer supported, but found Human-Embryo-Timelapse.py`; the file-listing fallback then sees only .py/README and reports `no media files or archives listed`. Better note: detect a script-only repo and report `Manual`/'script-only HF repo, use homepage'. Workaround here: route to the Zenodo record.
2. **HDF5 not supported** (`cetus-2014`). `datasets.load_dataset('zeahub/cetus-miccai-2014', streaming=True)` -> `ModuleNotFoundError: No module named 'h5py'` inside datasets' hdf5 builder; fallback lists `*.hdf5` files, none is in `MEDIA_EXT`, so `no media files or archives listed`. Same for N5/HDF5 Zenodo zips (`platynereis-whole-body-sbem`: `prepare` -> `no media found` after a 0.67 GB download).
3. **RAR extraction and unknown image extension** (`cca-intima-media-cyprus`). Download reports `n_media: 140` and `done` for a RAR (media inside archives is assumed), then prepare says `no media found`. Repro: `bsdtar -tf 100-IMT-ImagesCY.rar` lists 102 `*.CRI`; `unrar`/`unar` are not installed (rarfile needs them) but `/usr/bin/bsdtar -xf x.rar -C dir` extracts it fine on this Mac. `file x.CRI` says TIFF and `PIL.Image.open` reads it (768x576, mode P), but `.cri` is not in `IMAGE_EXT` (files.py). Suggested: fall back to `bsdtar` for .rar, and sniff content for unknown extensions inside archives (or add .cri).
4. **Zenodo record id redirect**. `https://zenodo.org/api/records/23098461` returns 302 to `/api/records/23098462`; a client that does not follow redirects sees an empty body (my `json.load` failed). The pipeline downloaded it fine, so this is only a hazard for ad hoc tools.
5. **Multi-disk zip** (`renji-esd-egc`): `BadZipFile: zipfiles that span multiple disks are not supported` after listing 20 x 5 GB parts. Should be recognised from names `*.z01..zNN` + `*.zip` and routed to drop/blocked at select time without a download attempt.
6. **BioStudies/BioImage Archive DOIs unsupported** (`biad3061-...`): `DOI resolves to an unsupported host: https://www.ebi.ac.uk/biostudies/studies/S-BIAD3061`. `https://www.ebi.ac.uk/biostudies/api/v1/studies/S-BIAD3061/info` returns `httpLink` (https://ftp.ebi.ac.uk/pub/databases/biostudies/S-BIAD/061/S-BIAD3061) and 169 files; a `biostudies` fetcher over that HTTP index would unlock every S-BIAD dataset.
7. **Tar-stream sampling takes the first members** (`gomez-human-embryo-timelapse`): 7 tars x 5 first members = 35 frames, 18 of them in-dataset near-duplicates, all from one well (`RI382-2`). Minor diversity loss; random/strided member choice would help.
8. cosmetic: `prepare.media_files` counts files before `exclude_paths` is applied (smids shows 280 although 94 Non-Sperm were excluded).
